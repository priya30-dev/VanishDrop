VanishDrop uses UDP to find devices (broadcast), TCP to send files, and HTTP or HTTPS (over TCP) for the web pages.

      

      

        
The devices in between

        

          
Hub
Repeats every signal to every port. Everyone sees everyone's traffic, which is why encryption matters. Rarely used now.

          
Switch
Learns which MAC address is on which port and sends frames only there. Your Wi-Fi router has one built in. See MAC addresses with arp.

          
Router
Moves packets between networks using IP addresses. tracert lists each router a packet passes.

          
Gateway
The router your laptop sends everything to when the address isn't on your own network. route and ipconfig show it.

        

        
Nearby send works without the internet because both laptops are on the same network: the Wi-Fi's switch delivers packets directly, no router hop needed.
